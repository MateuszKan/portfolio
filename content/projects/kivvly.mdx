## Description

Kivvly is a web app that helps remote workers find and share the best public spaces for work, such as cafés, libraries, and coworking spaces. Built with **Next.js**, **Firebase**, **Shadcn**, and **Tailwind CSS**, Kivvly offers a modern, responsive, and user-friendly experience.


## Technologies Used

- **Next.js** – A React framework optimized for performance, server-side rendering, and static generation.
- **Firebase** – A powerful backend-as-a-service used for authentication, database management, and real-time updates.
- **Shadcn** – A utility-first design system for building sleek and consistent UIs.
- **Tailwind CSS** – A utility-first CSS framework for quickly styling components with flexibility and efficiency.
